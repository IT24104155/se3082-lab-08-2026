# Sources and changes

Based on IT24200310's repository:
https://github.com/IT24200310/IT24200310_SE4060-MPI-Part1

Source revision: 4277e96 ("Completed Labsheet 8 activities").

The MPI examples, original instructions, cluster examples, spreadsheet, and reference results come from that repository. Files are organized by activity, with descriptive filenames. The duplicate HelloMPI.c/HelloMPI_solution.c source is represented once as Exercise01/hello_mpi.cpp. Processor-name buffers were enlarged to MPI_MAX_PROCESSOR_NAME, and the messaging examples now reject process counts below four.

Exercise03/estimate_pi.cpp is a new implementation because the source report describes Exercise 3 but its source code is absent. The Makefile and navigation documentation were added for this organized version. Imported timings, machine names, and graphs are the original author's evidence and have not been reproduced here.
