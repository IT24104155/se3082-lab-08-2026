Exercise 1 – Hello MPI
Objective
To execute a basic MPI program using multiple processes and observe the rank and processor name of each process.

Program
The HelloMPI.c program initializes MPI using MPI_Init(), obtains the rank of each process using MPI_Comm_rank(), and obtains the processor name using MPI_Get_processor_name().
Rank 0 displays a "Hello World" message, while the other processes display a normal process message.
Compilation
mpicxx HelloMPI.c -o HelloMPI

Execution
The program was executed using 1, 2, 4, and 8 MPI processes.
mpirun -np 1 ./HelloMPI
mpirun -np 2 ./HelloMPI
mpirun -np 4 ./HelloMPI
mpirun --oversubscribe -np 8 ./HelloMPI

Observations
For 1 process, only rank 0 was executed and it displayed the "Hello World" message. When multiple processes were used, rank 0 displayed the "Hello World" message and the remaining processes displayed the normal process message. All processes were executed on the same machine, DESKTOP-CQL9TFS.
The execution time increased when more MPI processes were launched in this experiment. This can occur because the program performs very little computation, while starting and managing additional MPI processes introduces communication and process-management overhead.

Exercise 2 – Parallel Sum Using MPI
Objective
To parallelize the addition of numbers from 1 to 10,000,000 using multiple MPI processes and measure the execution time for different numbers of processes.
Program
The MPI program divides the range of numbers among multiple processes. Each process calculates the sum of its assigned portion. The partial sums are then combined using MPI communication to obtain the total sum.

Compilation
mpicxx exercise2.cpp -o exercise2
Execution
The program was executed using 1, 2, 4, and 8 MPI processes.
mpirun -np 1 ./exercise2
mpirun -np 2 ./exercise2
mpirun -np 4 ./exercise2

Exercise 3 – Estimating Pi Using MPI
Objective
To estimate the value of π using the Monte Carlo method and parallelize the calculation using MPI.

Method
The program generates random points within a square. Points that fall inside the quarter circle are counted. The value of π is estimated using the ratio between the points inside the circle and the total number of points.
The calculation is divided among multiple MPI processes, and the results from the individual processes are combined to obtain the final estimate of π.

Execution
The program was executed using 1, 2, 4, and 8 MPI processes.
mpirun -np 1 ./exercise3
mpirun -np 2 ./exercise3
mpirun -np 4 ./exercise3
mpirun --oversubscribe -np 8 ./exercise3

The estimated value of π was close to the mathematical value of π (approximately 3.14159) for all process counts. The small differences are expected because the Monte Carlo method uses randomly generated points.
The execution time decreased as the number of MPI processes increased. The lowest measured execution time was obtained using 8 processes.
The results demonstrate that MPI can be used to distribute the computational workload
